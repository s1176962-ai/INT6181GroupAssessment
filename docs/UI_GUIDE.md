# 桌面界面规范

## 视觉与布局

- 背景使用浅灰蓝，内容区使用白色；品牌栏为深蓝灰，主操作为青绿色。
- `theme.py` 集中管理颜色、字体、控件状态和间距，不在业务服务中定义样式。
- 顶栏右侧依次展示访客身份和登录入口；登录后替换为用户名及退出登录/切换账户。
- 登录表单水平居中且限制宽度，保持靠上；主页面内容限制宽度，保留页边空白。
- 首页使用统计摘要和功能卡片；窄窗口时功能卡片改为单列。
- 主要动作使用 Accent 按钮，辅助动作使用 Quiet 按钮，删除动作使用 Danger 按钮。
- 答题页显示进度条、题目层级和选中状态；正确/错误反馈使用文字加背景色，不单独依赖颜色。
- 管理表格使用统一表头、行高、交替行背景和选中颜色。
- 文本编辑区和表格使用自身滚动，不带动外层页面。长页面仍可通过外层滚动条访问。

## 保持不变的行为

权限校验、题库字段、密码、学习进度、错题规则和账号管理逻辑不因样式更改而变化。中文与英文共用同一布局，题目数据不自动翻译。运行依然只使用 Python 标准库和 Tkinter。

## 检查范围

检查登录、普通用户首页、管理员首页、答题反馈、题库和用户表格，以及英文文本。建议分别在默认窗口、较窄窗口和最大化窗口查看。样式不能覆盖键盘焦点、禁用状态或选中状态。

修改布局时先运行全部 unittest，再打开实际窗口检查视觉。界面外观与业务测试是不同的验证项目。

## 笔记本布局

默认紧凑布局和自动窗口尺寸。设置中的窗口与布局可选择自动、960x640、1080x720、1280x800；尺寸自动限制在当前屏幕范围内并预留任务栏空间，不修改系统分辨率。紧凑首页省略辅助说明，足够宽时使用三列卡片；关闭紧凑布局恢复说明和宽松间距。偏好保存在本机 data/display.json。长内容仍需滚动。

四个功能入口在正常宽度下采用两行两列；六个管理员入口在紧凑且足够宽时采用三列。窄窗口继续降为单列。
